# SMART STUDENT LIFE MANAGER

## 📌 Project Description

**Smart Student Life Manager** is a simple Python-based application designed to help students manage important aspects of their daily academic and personal life in one place.

The program provides four main features:

1. 💰 **Expense Manager**
2. 📚 **Attendance Manager**
3. ✅ **Task Manager**
4. 📊 **Analytics**

The application uses a simple menu-driven interface, making it easy for beginners to understand and use.

---

## 🎯 Objectives

The main objectives of this project are:

* To manage daily student expenses.
* To keep track of subject-wise attendance.
* To maintain a list of academic and personal tasks.
* To monitor completed and pending tasks.
* To provide basic student-life analytics.
* To demonstrate the use of fundamental Python programming concepts.

---

## ⚙️ Features

### 1. Expense Manager

The Expense Manager allows users to:

* Add a new expense.
* Enter the expense name.
* Enter the amount spent.
* Assign a category to the expense.
* View all recorded expenses.
* Calculate total expenses.

### 2. Attendance Manager

The Attendance Manager allows users to:

* Add subjects.
* Enter the number of classes attended.
* Enter the total number of classes.
* Calculate attendance percentage.
* View attendance for all subjects.
* Calculate average attendance through Analytics.

### 3. Task Manager

The Task Manager allows users to:

* Add new tasks.
* View all tasks.
* Check whether a task is pending or completed.
* Mark tasks as completed.

### 4. Analytics

The Analytics section provides a summary of:

* Total expenses.
* Average attendance.
* Total number of tasks.
* Number of completed tasks.
* Number of pending tasks.

## ▶️ How to Run

### Step 1

Install Python on your computer.

### Step 2

Save the program as:

```text
student_life_manager.py
```

### Step 3

Open the terminal or command prompt.

### Step 4

Run:

```text
python student_life_manager.py
```

### Step 5

Select an option from the main menu.

## 📂 Data Storage

The current version stores data temporarily using Python data structures:

```python
expenses = []
attendance = {}
tasks = []
```

This means that the data exists only while the program is running.

When the program is closed, the stored information is lost.
